# Named Heads

**Named Heads** 是一个适用于 Minecraft Java Edition 26.2 的纯原版数据包。

它可以将原版头颅通过铁砧命名为 Minecraft 玩家名，并自动转换为对应玩家的头颅。

例如：

```text
僵尸的头颅
→ 铁砧命名为 Notch
→ Notch 的玩家头颅
```

整个过程不需要执行任何命令，也不需要安装 Fabric、NeoForge 或服务器插件。

## 支持版本

* Minecraft Java Edition 26.2

* Named Heads v1.0.0

## 功能

将以下原版头颅通过铁砧命名为玩家名后，可以自动转换成对应的玩家头颅：

* 骷髅头颅

* 凋灵骷髅头颅

* 僵尸的头

* 苦力怕的头

* 末影龙的头

* 猪灵的头

* 玩家头颅

已有的玩家头颅也可以再次通过铁砧改名，从一个玩家的头颅转换为另一个玩家的头颅。

例如：

```text
Notch 的玩家头
→ 铁砧改名为 jeb_
→ jeb_ 的玩家头
```

## 玩家名规则

用于铁砧命名的名称需要符合 Minecraft 玩家名格式：

* 长度为 1～16 个字符；

* 可以使用英文字母 `A-Z`、`a-z`；

* 可以使用数字 `0-9`；

* 可以使用下划线 `_`。

例如：

```text
Notch
jeb_
Steve123
Player_01
```

包含空格、中文、特殊符号或超过 16 个字符的名称不会被转换。

## 安装方法

下载对应版本的：

```text
named-heads-v1.0.0.zip
```

将 ZIP 文件直接放入世界的：

```text
<世界目录>/datapacks/
```

例如：

```text
.minecraft/
└─ saves/
   └─ MyWorld/
      └─ datapacks/
         └─ named-heads-v1.0.0.zip
```

不需要解压 ZIP。

进入世界后执行：

```text
/reload
```

也可以重新进入世界。

## 使用方法

1. 获得一个受支持的原版头颅；

2. 将头颅放入铁砧；

3. 将其名称修改为目标 Minecraft 玩家名；

4. 取出头颅；

5. 数据包会自动将它转换为对应玩家的头颅。

普通左键取出和 Shift + 左键快速移动均可以正常使用。

## 自动处理范围

Named Heads v1.0.0 可以自动处理：

* 玩家快捷栏；

* 玩家主背包；

* 铁砧 Shift + 左键取出的头颅；

* 普通左键拿在鼠标上的头颅；

* 生存模式；

* 创造模式。

转换完成后，头颅会使用 Minecraft 原生的玩家 Profile 机制加载对应玩家的皮肤。

## 物品数据保留

转换时会尽量保留原头颅已有的其他物品数据，包括：

* 物品数量；

* Lore；

* Custom Data；

* 其他与转换无关的物品组件。

原铁砧名称会被作为转换请求消耗，最终玩家头颅由其玩家 Profile 决定。

## 不会被转换的物品

以下物品不会受到影响：

* 没有改名的头颅；

* 名称格式不合法的头颅；

* 普通非头颅物品；

* 没有新铁砧名称的玩家头颅。

## 已知限制

v1.0.0 暂不自动处理：

* 合成栏中的物品；

* 副手；

* 盔甲栏；

* 箱子等外部容器中的物品；

* 末影箱中的物品。

这些位置中的头颅一旦被移动到玩家快捷栏、主背包或正常鼠标 Cursor 流程中，仍可由数据包正常处理。

本数据包不会主动连接 Mojang API 或第三方玩家查询服务，玩家皮肤由 Minecraft 原生 Profile 机制处理。

## 数据包结构

源码中的主要数据包结构为：

```text
named-heads/
├─ pack.mcmeta
└─ data/
   ├─ minecraft/
   └─ named_heads/
```
